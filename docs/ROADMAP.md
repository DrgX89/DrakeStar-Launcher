# Roadmap

**v0.1 (hecho):** núcleo con tests, CLI, esquemas, ejemplos, marca vectorial, CI, documentación.

**v0.2 — Local Forge usable:** `drakestar-net` (descarga + SHA-256 + caché), `drakestar-proc` (arrancar/parar DrakesPurpur, logs, consola), preset Slimefun reproducible, gestión de plugins/mundos, prueba real contra un JAR de DrakesPurpur.

**v0.3 — Shell gráfico:** Tauri + Svelte con las rutas de `ui/routes.json`, tema DrakeStar, perfiles CRUD + import/export.

**v0.4 — DrakesJava:** instalación de versiones/loaders, JRE gestionado, modpacks, memoria.

**v0.5 — Online:** DrakesCraft, accesos rápidos, estado (ping) del servidor.

**v0.6 — Actualizaciones:** manifiestos firmados, canales por componente, rollback.

**v1.0 — DrakesRust:** solo cuando exista un cliente Rust que demuestre conexión a DrakesPurpur 26.2 y comportamiento correcto de GUIs de Slimefun. Hasta entonces el modo se marca *experimental*.

Pendiente transversal: instaladores por plataforma, tests con jugadores reales, Geyser/Bedrock (fuera de alcance por ahora), accesibilidad de la UI.
